# 전국 공공리포트 출처 확장 계획

## 목적과 경계

전국 단위 확장은 출처 수를 급히 늘리는 작업이 아니라, 발행일·공식 링크·권리 상태를 검증할 수 있는 공개 리포트 출처를 분야별로 균형 있게 추가하는 작업입니다. 수집은 공개 HTML, 공식 RSS/Atom, 공개 첨부 링크, 정상적인 브라우저 렌더링으로만 합니다. API, 숨은 JSON/XHR, 로그인·CAPTCHA 우회는 사용하지 않습니다.

기본 수집 창은 최근 7일입니다. 최초 연결 시에도 이 창보다 오래된 자료를 백필하지 않으며, 이미 발행된 문서는 다음 날짜의 발행 후보에서 제외합니다.

현재 활성 수집 출처는 27곳입니다. 동일 콘텐츠를 중복 수집하지 않고, 기관별로 성격이 분리된 공개 리포트 게시판만 최대 3개까지 연결합니다.

### 다중 게시판 확장

- 하나금융연구소: 연구보고서, 하나금융포커스, 대한민국 웰스 리포트
- 한국고용정보원: 연구사업보고서, 고용이슈, 고용동향브리프
- 해양수산부: 보도자료, 정책게시판

해양수산부 간행물은 현재 공개 목록이 비어 있어 활성 출처로 등록하지 않았습니다. 정상적인 목록과 발행일이 확인되면 세 번째 게시판으로 추가합니다.

## 도입 순서

1. 다음 묶음은 KOTRA·한국고용정보원·한국해양수산개발원 3곳으로 제한해 조사합니다.
2. 기관별로 목록·상세 fixture와 parser 회귀 테스트를 먼저 작성합니다.
3. 공식 파일 링크가 확인되면 MIME/서명 검증과 만료 여부를 확인하고, 확인 전에는 `OFFICIAL_PAGE_ONLY`로 둡니다.
4. 최근 7일 수집 결과를 자동 검수 정책과 관리자 화면에서 확인하고, 3회 연속 smoke 성공 시 출처를 활성화합니다.
5. 매주 최대 3개 출처만 다음 묶음으로 추가합니다. 오류율, 중복률, 링크 성공률을 확인한 뒤 다음 묶음을 시작합니다.

## 2026-08-21 확장 기록

- 국토연구원: 목록에서 공개 상세 페이지와 발행일을 확인했고, 상세 페이지의 `소개` 문단을 공식 요약으로 읽습니다. 파일 링크는 내부 API 형태여서 호출하지 않으며 `OFFICIAL_PAGE_ONLY`로 운영합니다. fixture와 live smoke를 통과했고 DB에는 비활성 출처로 등록했습니다.
- 한국교육개발원: 공개 목록의 상세 이동은 POST 폼이지만, 전용 adapter가 실제 브라우저에서 해당 폼을 제출하도록 구현했습니다. fixture와 live smoke를 통과했으며 직접 파일은 권리 고지에 따라 연결하지 않습니다.
- 한국노동연구원: 후보 목록 URL이 현재 라이선스 오류 페이지로 전환됩니다. 상태 adapter가 이를 `DEGRADED`로 기록하며, 우회 URL 추정·로그인·라이선스 우회는 하지 않습니다.
- 과학기술정책연구원: 공개 상세 요약은 fixture에서 회귀 검증했지만, Playwright headless 화면에서 목록 항목을 안정적으로 찾지 못했습니다. 일반 브라우저 화면 구조와의 차이를 분석할 때까지 비활성으로 둡니다.
- 산업연구원·에너지경제연구원·통일연구원: 공개 목록과 상세 페이지의 요약/초록을 확인해 독립 YAML과 list/detail fixture를 추가했습니다. JavaScript로 생성되는 직접 파일 링크는 호출하지 않고 공식 상세 페이지 연결만 사용합니다.
- 한국환경연구원·대외경제정책연구원: 공개 목록·상세 요약 수집과 live smoke를 검증했습니다. 직접 파일 링크의 만료·권리 조건을 검증하기 전에는 `LINK_ONLY`로 둡니다.
- 한국조세재정연구원: 공개 목록의 JavaScript 링크가 제출하는 공개 POST 폼을 전용 adapter로 처리했습니다. fixture와 live smoke를 통과했고, 원문 파일은 직접 연결하지 않고 공식 목록 페이지 연결을 유지합니다.
- 국가안보전략연구원: 공개 이슈브리프 목록의 `setView` 링크를 공식 상세 URL로 복원하고, 상세 페이지의 발행일·초록·공식 다운로드 링크를 읽는 전용 adapter를 추가했습니다. 최근 7일 실제 실행에서 3건을 발견했고 실패는 없었습니다.
- KOTRA 해외시장뉴스: 공개 첫 화면의 목록·상세 HTML에서 항목 ID, 발행일, 본문 요약과 공식 첨부 링크를 검증했습니다. 별도 API나 숨은 JSON/XHR은 사용하지 않습니다.
- 한국고용정보원: 공개 발간물 목록의 `goDetail` 인자를 공식 상세 URL로 복원하고, 상세의 등록일·공식 요약·다운로드 링크를 fixture와 smoke로 검증했습니다.
- 한국해양수산개발원: 공개 연구보고서 목록과 상세 발간일을 연결했습니다. 파일은 공식 문서 뷰어가 안정적으로 제공되는 경우만 전달 대상으로 판정하며, 그 전에는 공식 상세 페이지를 우선합니다.
- 금융위원회: 공개 정책·보도자료 목록의 발행일과 공식 첨부 링크를 연결했습니다. 채용·입찰·행사 공고는 제목 필터에서 제외합니다.
- KB경영연구소: 로그인 없이 공개된 리포트 목록·상세·공식 다운로드 링크만 연결했습니다. 민간 자료도 기본 권리 상태는 `LINK_ONLY`이며, 원본의 저장·재배포는 하지 않습니다.
- 이번 묶음의 5개 출처는 목록·상세 읽기 전용 smoke를 3회 연속 통과했습니다. 최근 7일에 해당하지 않는 항목은 기존 수집 창 필터에서 자동 제외됩니다.

## 완료 기준

- 각 활성 출처에는 독립 YAML, adapter 또는 선택자, list/detail fixture, parser 테스트, live smoke가 있습니다.
- 최근 7일 기준으로만 신규 자료를 수집하며, 수집 시점에 과거 목록을 일괄 승인하지 않습니다.
- 공개 화면에는 관리자 승인과 snapshot 생성까지 끝난 자료만 보입니다.
- 공식 파일을 영구 보관하지 않으며, 권리가 불명확하면 공식 상세 페이지 링크만 제공합니다.
